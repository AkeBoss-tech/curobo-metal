# Fused FK profiling artifacts

`benchmark-mps.json` contains synchronized raw timing samples for the
runtime-compiled fused Metal prototype on the Apple M4. It separates first
public use, validation-only, fused-core, and public end-to-end measurements.

The command and interpretation are documented in
`docs/profiling/fused-fk.md`. The preliminary development run is intentionally
not part of the committed evidence set.
