# Security policy

## Supported versions

Security fixes are provided for the newest published `curobo-metal` alpha or
stable release. Pre-release APIs may change as compatibility work progresses.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository:

<https://github.com/AkeBoss-tech/curobo-metal/security/advisories/new>

Include the affected version/commit, platform, reproduction steps, impact, and
any proposed mitigation. Maintainers will acknowledge a complete report as soon
as practical and coordinate remediation and disclosure with the reporter.

General correctness bugs and unsupported CUDA/Metal parity cases are not
security vulnerabilities and should use the public issue tracker.
